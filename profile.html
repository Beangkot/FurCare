About FurCare

FurCare is a frontend-only demo built with semantic HTML5, CSS3 and vanilla JavaScript (ES6+). It showcases a modern, responsive, Material-inspired interface for managing pet health — including vaccination tracking, feeding schedules, appointments and alerts. No backend, database or authentication is involved.
